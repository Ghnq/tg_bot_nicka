### Структура бота

При команде /start пользователь видит меню с тремя кнопками:

1. **Кнопка 1 → Мини-приложение** (Telegram Mini App)
   - Пользователь автоматически залогинен через Telegram
   - Доступны практики для осознанности и снижения тревожности
   - В будущем: материалы для чтения

2. **Кнопка 2 → Скачать гайд**
   - Лид-магнит: "7 шагов для преодоления прокрастинации"

3. **Кнопка 3 → Записаться к Веронике**
   - Ведёт в личные сообщения к Веронике для записи на консультацию

### Двойная функция бота

1. **Привлечение новых клиентов** — через лид-магнит (гайд) и прогрев через практики
2. **Инструмент для текущих клиентов** — Вероника рекомендует бот своим клиентам для выполнения конкретных практик между сессиями
