# 🚀 Инструкция по запуску бота

## 1. Установи Python
Скачай Python 3.10+ с https://python.org и установи.

## 2. Установи зависимости
Открой терминал (cmd / PowerShell) в папке с файлами и выполни:

```
pip install -r requirements.txt
```

## 3. Получи токен бота
1. Открой Telegram, найди @BotFather
2. Напиши /mybots → выбери @PositiveBatteryBot → API Token
3. Скопируй токен

## 4. Пропиши свои данные в bot.py
Открой bot.py и замени:
- `ВАШ_ТОКЕН_ОТ_BOTFATHER` — на токен из шага 3
- `https://ВАШ_САЙТ.ru` — на URL твоего Mini App (ОБЯЗАТЕЛЬНО https://)

## 5. Запусти бота
```
python bot.py
```

## 6. Настрой Mini App в BotFather (важно!)
Чтобы кнопка открывала твой сайт как Mini App:
1. Напиши BotFather: /newapp
2. Выбери своего бота
3. Укажи URL своего сайта

---

## Где запускать бота постоянно?
Для постоянной работы бота нужен сервер. Варианты:
- **Railway.app** — бесплатно, просто (рекомендую для старта)
- **Render.com** — бесплатный тариф есть
- **VPS/хостинг** — любой сервер с Python
